# CEATS · 公考量化分析系统

> **Civil Service Exam Analysis & Tracking System**
> 面向公务员考试（行测）备考场景的本地量化分析工具 —— 把「感觉复习得不够」变成
> 「哪个模块、哪个考点、差多少」的可量化结论。

软件工程课程设计项目（实验 1 ~ 实验 11 的整合交付物）。

---

## 1. 项目解决什么问题

| 备考痛点 | 具体表现 | 本项目的应对 |
| --- | --- | --- |
| 招考信息碎、乱、杂 | 公告分散在多个官网，容易错过报名节点 | 公告聚合模块：多站点定向抓取 + 关键词标记 + URL 去重 + 断网降级导航 |
| 复习进度难量化 | 「今天做了 60 题」无法说明水平是否提升 | 成绩记录模块：正确率与单题耗时即时计算，历史数据全部落库 |
| 弱项不明确 | 只知道「数量关系差」，说不出差在哪 | 弱项诊断模块：模块/考点两级聚合 + 三维加权评分 + 效率预警 |

## 2. 功能一览

| 模块 | 核心能力 |
| --- | --- |
| 公告聚合 | 抓取国家公务员局 / 广东省人事考试局公告，按关键词（报名、公告、职位表…）标记，重复自动去重；全部站点失败时降级为官方入口链接导航 |
| 成绩记录 | 校验日期、模块、考点、题数、对题数、用时共 6 类输入；支持 `25:30`、`1:05:00`、`1500` 三种用时写法；录入后立即返回正确率与速度等级 |
| 弱项诊断 | 三维加权评分（正确率 0.6 + 效率 0.3 + 稳定性 0.1），定位薄弱考点，预警单题耗时超 60 秒的模块 |
| 可视化 | 五角能力雷达图、正确率与耗时双轴趋势图、模块得分排名图（中文渲染），可用 `--show` 弹窗展示 |
| 知识库 | 行测公式、解题技巧、申论模板共 13 条专家规则，支持关键词与正文模糊检索 |
| 备考计划 | 考试倒计时（每次启动自动提醒）+ 按公考黄金比例把目标总分拆解到各模块，并与当前正确率比对差距 |
| 闪卡抽测 | 从知识库随机抽题，终端手打作答，本地算法自动判分（无需大模型），输出得分、等级与遗漏要点 |
| 错题备忘 | 录入成绩可打 `is_wrong` 标记，支持事后补打/取消；自动生成「今日优先复盘清单」（错题多 + 正确率低 + 耗时长的考点优先） |
| 报告与备份 | 一键导出 Markdown / CSV 诊断报告；一键备份数据库为带时间戳的快照，支持安全还原 |
| 数据管理 | 一键初始化建表与字典、演示数据写入、备考目标设置 |

### 功能特性

- **弱项可视化**：五角能力雷达图、正确率与耗时双轴趋势图、模块综合得分排名图，弱项模块自动标红。

## 4. 快速开始

### 4.1 环境要求

- Python 3.10+（开发环境为 3.12.4）
- Windows / macOS / Linux 均可（图表中文渲染在 Windows 下自动使用 Microsoft YaHei）

### 4.2 安装

```bash
git clone https://github.com/cykeblaty334/Se_Lab.git
cd Se_Lab
pip install -r requirements.txt
```

### 4.3 初始化并试跑

```bash
python -m src.main init                    # 建库 + 写入模块/考点/知识库字典
python -m src.main record --module 数量关系 --topic 行程问题 \
       --total 20 --correct 9 --duration 25:30
python -m src.main report                  # 查看弱项诊断报告
python -m src.main chart                   # 生成雷达图 / 趋势图 / 排名图
python -m src.main chart --show            # 生成后弹窗查看（答辩演示用）

python -m src.main plan set --date 2027-11-28 --target 135   # 设定考试日期与目标总分
python -m src.main plan                    # 倒计时 + 各模块建议目标正确率
python -m src.main record --module 资料分析 --total 20 --correct 8 \
       --duration 30:00 --wrong           # --wrong 打上错题标记
python -m src.main review                  # 今日优先复盘清单（错题多 / 正确率低 / 耗时长）
python -m src.main quiz --count 5          # 闪卡抽测，终端手打作答自动判分
python -m src.main export --format all     # 导出 Markdown + CSV 诊断报告
python -m src.main backup                  # 一键备份数据库（带时间戳）
python -m src.main restore                 # 从最新备份还原（还原前自动再备份一次）
```

## 6. 核心算法

### 6.1 弱项诊断

```
综合得分 = 0.6 × 正确率分 + 0.3 × 效率分 + 0.1 × 稳定性分

正确率分 = 模块加权正确率（0~1）
效率分   = min(1, 45 / 单题平均耗时秒数)          # 45 秒/题为满分基准
稳定性分 = max(0, 1 - 正确率标准差 / 0.2)         # 波动越小分越高
```

- 综合得分 < 60 判为**弱项**；未练习的模块**不参与评分**，统一排在结果末尾；
- 单题耗时 > 60 秒的模块进入**效率预警**；
- 所有阈值与权重集中在 [src/config.py](src/config.py)，可按个人情况调整。

### 6.2 目标分拆解（黄金比例缩放）

```
建议正确率 = 黄金基准正确率(GOLDEN_RATIO) × 目标总分 / 135
最终取值   = clamp(建议正确率, 30%, 95%)
```

黄金基准为 135 分档：言语 75%、判断 75%、资料 85%、数量 60%、常识 55%。
以 135 分为基准按比例缩放，既保证目标分与各模块难度分布自洽，又避免出现 100% 这类不现实目标。
行测目标分 = 目标总分 − 申论预期分，再由各模块参考满分（合计 100 分）换算成模块建议得分。

### 6.3 闪卡判分（本地算法，无需大模型）

1. **归一化**：全角转半角、`×`/`x`/`X` 统一为 `*`、统一小写，中文标点归一；
2. **片段切分**：按空白与标点切分标准答案，得到若干「要点片段」（保留空白切分，避免中文片段粘连）；
3. **加权覆盖率**：公式变量与数字等字母数字片段权重 2，中文片段权重 1；

```
得分 = 100 × 命中片段权重和 / 全部片段权重和
```

- 作答完全包含标准答案（去空白后）直接记 100 分；
- ≥ 60 分判定通过，并按 100 / 85 / 60 分档输出「完全正确 / 基本正确 / 部分正确 / 需加强」；
- 未作答记 0 分，同时列出**遗漏要点**便于针对性复习。

### 6.4 复盘优先级

```
优先级 = 3.0 × 错题数 + 2.0 × (1 − 正确率) + 1.5 × max(0, 单题耗时 / 45 − 1)
```

在最近 30 天的考点聚合数据上计算，取优先级最高的 3 个考点，并自动附带对应知识库卡片。
权重组合同样可在 [src/config.py](src/config.py) 中调整。

只有满足以下任一条件的考点才会进入清单，避免为了凑满条数而推荐已掌握良好的考点：

```
错题数 > 0  或  正确率 < 60%  或  单题耗时 > 45 秒
```

若窗口内所有考点状态都正常，清单会直接说明"均未触发复盘条件"，而不是列出健康考点。

## 8. 数据安全说明

- 所有练习成绩仅保存在本地 `data/ceats.db`，不上传任何服务器；
- 爬虫只抓取公开列表页的标题与链接，遵守 robots 协议、低频访问、不抓取正文；
- 抓取失败时不会阻塞程序，而是给出明确原因并降级为官方入口导航；
- 备份使用 SQLite 官方 `Connection.backup` 接口生成一致性快照，避免直接复制文件时
  写到一半的脏数据；还原前会校验文件头与核心表，并**自动再备份一次当前库**，
  防止误还原覆盖已有成绩。
